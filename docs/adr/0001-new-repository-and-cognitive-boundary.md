# ADR-0001：建立“认知融接”新仓库，不继承旧 DCF 工程实现

- 日期：2026-08-27
- 状态：accepted

## 背景

旧 `dcf-chatgpt-microcore` 在长期探索中叠加了多代互不相同的工程路线。继续在旧仓库内重构，会让旧实现、旧目录和历史兼容关系持续影响新的架构判断。

同时，当前项目与更广义“赛博义肢”的方向逐渐趋同，但本项目有明确边界：主要服务人的认知活动，而不是无限扩张到所有身体、感官和现实增强能力。

## 决定

建立新的 GitHub 仓库 `renzhi-rongjie`，中文项目名为“认知融接”。

新仓库从零开始设计和实现：

- 迁移仍有认知价值的 ADR、项目文档和项目检查点；
- 不迁移任何旧工程实现；
- 不把旧源码、测试、脚本、宿主、兼容层、构建产物和旧目录结构作为新工程母本；
- 旧仓库保持原样，继续作为历史事实源与必要时的考古来源；
- 历史文档在新仓库中明确放入 `docs/history/`，不冒充当前权威架构。

## 结果

“认知融接”的第一份工程代码将来自当前架构重新设计，而不是旧 DCF 的代码搬运。项目历史被保留，但实现惯性被切断。
