# 当前方向

> 本文是 2026-08-27 建立新仓库时的当前项目入口。它用于快速恢复“现在准备做什么”，历史推演与原始 ADR 见 `docs/history/`。

## 1. 项目边界

项目中文名称为**认知融接**。它与更宽泛的“赛博义肢”构想逐渐趋同，但这里主动收窄到认知领域：记忆、理解、判断、知识、AI 协作、项目认知以及与这些活动直接相关的数字工具和长期状态。

## 2. 第一个功能：可复用战役世界

战役蓝图不是整个项目，而是认知融接的第一个功能与第一个自举容器。

设计阶段把软件或功能表示为可复用关卡蓝图：目标、关键验收门、串并联路线、依赖、通过条件与证据要求。运行阶段，中央地图把设计路线与真实执行路线叠在一起；节点是否点亮由证据支持，而不是执行 AI 的自述。

## 3. 第一阶段自举

为避免鸡生蛋问题，正式 Godot 世界出现前先使用临时脚手架：

- 简易战役地图；
- DeepSeek Harness 作为优先执行层；
- Durable AI Workflow：优先尝试 DeepSeek Harness 官方/社区/自制插件，若不适合则优先 DBOS；
- 独立保存执行与 Workflow 证据；
- 第二层叙事 AI 读取最小充分证据，生成中文机器行为叙事并写入数据库；
- 地图只消费蓝图和叙事/战役状态投影，不直接理解 Harness 原始轨迹。

## 4. 数据关系主干

长期目标不是把所有内容塞进一段上下文，而是让数据库承担关系骨架：

`执行证据 → 叙事片段 → 总工程师决策 → 执行约束 → 下一轮执行`

每个叙事片段可以关联一个或多个证据；总工程师决策关联其依据的叙事片段。执行 AI 只读取当前对自己生效的执行决策投影。

第三层总工程师还有第二条独立反馈通路：对叙事 AI 提供“怎样观察、怎样采样、怎样压缩、怎样绑定关系”的叙事校准。执行决策与叙事校准不得混为一类。

## 5. 中文可见语义

叙事层自然语言和中央可见语义默认使用中文。稳定 ID、字段名、枚举等机器关系层可以使用英文，但不能为了生成地图方便而把人的认知界面退化成英文术语堆。

## 6. 爆炸范围修复

临时战役地图、AI Harness、AI Workflow 三个基础能力形成可用闭环后，立即冻结继续扩功能，进入爆炸范围修复：盘点自举期全部产物、恢复血缘、区分长期事实/历史证据/可重建投影/临时脚手架/缓存与未知物，完成归位后再继续正式收编。

## 7. 正式宿主方向

Godot 当前是正式世界容器 / Host Runtime 的优先候选。收编不意味着把成熟 Harness、Workflow Runtime、数据库等全部重写成 GDScript；正式世界主要接管它们的身份、状态、入口、关系、证据、叙事和控制面。

## 8. 当前施工纪律

新仓库不搬旧工程实现。任何新实现都应从当前问题重新选择结构，不把旧 DCF 的源码、目录、宿主、脚本、测试和兼容层当默认母本。
