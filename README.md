# 认知融接

认知融接是 DCF 的新一代工程仓库。项目以**认知活动**为明确边界，目标是让人的判断、AI 的执行、长期知识与状态、工具和工作流能够在同一个可观察、可追溯、可持续演化的工作世界中连接起来。

本仓库从零开始，不继承旧 DCF 的工程实现。

当前第一阶段不是把旧代码搬过来重构，而是先建立一套可自举的最小工作闭环：

1. 简易、临时的战役地图；
2. AI Harness，当前优先考虑 DeepSeek Harness；
3. AI Workflow，优先尝试 DeepSeek Harness 内生/插件式 Workflow，必要时采用 DBOS；
4. 执行证据 → 中文机器行为叙事 → 战役地图投影；
5. 三个基础能力闭环后立刻进入爆炸范围修复，再逐步收编进 Godot 驱动的正式世界容器。
