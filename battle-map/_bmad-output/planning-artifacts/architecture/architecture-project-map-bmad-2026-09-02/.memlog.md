- (decision) AD-1 Project Shape Semantic Store is the canonical durable project cognition model: minimal node semantics plus first-class project relations and small current boundary state; raw execution facts are not durable project semantics. Binds all Battle Map capabilities; prevents fact-archive drift and external artifacts becoming semantic authority.
- (decision) AD-2 Battle Map, Project Narrative, and Temporary Fact Workset are separate durable-responsibility classes: Map preserves current shape/relations/frontier boundaries; Narrative preserves only route/method/process lessons worth reusing; temporary facts remain outside durable project semantics. Prevents narrative becoming replay log and Map becoming evidence archive.
- (decision) AD-3 Project Weaving is the only ingress from raw external reality into semantic candidates: incremental source reading enters a temporary workset, is distilled to relation/boundary/lesson implications, and produces candidates; undistilled facts cannot write adopted project shape. Prevents raw source events from bypassing cognition and polluting the semantic core.
- (decision) AD-4 Any adopted change that alters project shape has one atomic consistency boundary: the complete affected relation set and dependent current boundary state become visible together or not at all. Prevents partial topology and contradictory frontier state across independently built units.
- (decision) AD-5 Advancement is a read/decide/dispatch plane, not a structural-cognition writer: it reads one coherent project-shape snapshot, selects the next action class, resolves required cognitive responsibility, and compiles a frozen bootstrap; it cannot derive shape directly from raw facts or inject new decisions into a running worker. Prevents orchestration from silently rewriting semantics or destabilizing execution.
- (decision) AD-6 Cognitive Runtime composes responsibility instances from Persona + Authority + Skill bundle + Workflow protocol + Handoff contract + Session binding; reusable definitions are versioned separately from project state and the bootstrap binds exact versions. Prevents hard-coded job rosters, hidden authority, and unrecoverable role drift.
- (decision) AD-7 Workers execute only inside their frozen bootstrap and native execution/verification runtime; worker-local todo/tool history remains local, and worker outcomes return to Weaving instead of directly mutating adopted Project Shape. Independent verification uses a genuinely separate responsibility boundary. Prevents project command logic from leaking into implementation loops and implementation facts from becoming authority.
- (decision) AD-8 Frontier, route availability, UI views, and specialized graph/search indexes are derived projections of Project Shape plus current satisfied/unknown/blocking boundaries; they are rebuildable and never competing sources of truth. Prevents duplicated state ownership and hand-maintained frontier divergence.
- (decision) AD-9 External sources retain raw-fact authority and adapters only translate/read them; external method systems may be compatibility providers but never define Battle Map public ontology or canonical semantic ownership. Prevents brownfield compatibility from re-shaping the native product around BMAD or any other provider.
- (direction) Design paradigm: hexagonal architecture around a relation-first Project Shape semantic core; source systems and worker runtimes attach through ports/adapters, while Weaving is an application pipeline and Advancement is a policy-driven command service.
- (constraint) Do not choose physical database, graph engine, UI framework, model provider, deployment topology, fixed thresholds, or fact-retention policy at architecture-spine altitude without evidence.
- (event) Chief Engineer approved relation-first Project Shape spine direction after PRD finalization and data-philosophy correction: remove facts, retain relations; formal architecture distillation started after Qoder credit exhaustion.
- (decision) Reviewer correction: all semantic-candidate producers, including Weaving and deliberate cognitive shaping, emit one native Project Shape Candidate Delta contract; Weaving remains the only ingress specifically from raw external facts.
- (decision) Reviewer correction: one Semantic Mutation Port is the sole writer of adopted Project Shape. Authority workflows decide; the mutation port commits. No adapter, worker, Weaving stage, or authority implementation writes canonical shape directly.
- (decision) Reviewer correction: adopted Project Shape transitions create one coherent semantic version; frontier and every derived view/index are version-bound projections and a dispatch cannot combine results from different semantic versions.
- (decision) Reviewer correction: Project Narrative may adopt a meaningful method/process/research lesson even when Project Shape does not change; narrative retention is driven by reusable lesson value, not by structural mutation logging.
